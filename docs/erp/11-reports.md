# 11. التقارير والقوائم المالية

## 11.1 مبادئ التقارير

- كل تقرير يُبنى من **القيود المرحّلة فقط** (`status = POSTED`).
- فلاتر قياسية: الفترة/التاريخ، الشركة، الفرع، مركز التكلفة، العملة (أساسية فقط للتقارير المالية).
- كل رقم قابل للنقر → يفتح تفاصيله (كشف حساب → القيد → المستند المصدر). "التتبع الكامل".
- تقارير ثقيلة تعمل عبر طابور وتُسلّم كملف (Excel/PDF) مع إشعار جاهزية.

## 11.2 ميزان المراجعة

```
الحساب | مدين الفترة | دائن الفترة | رصيد مدين تراكمي | رصيد دائن تراكمي
```

- يُحسب من `account_period_balances` (التجميع) وليس من الأسطر مباشرة؛ لكل شركة/فرع/فترة.
- تحقق أساسي: مجموع المدين = مجموع الدائن دائماً (إلا في فترة إقفال معلقة).

## 11.3 قائمة الدخل

```
الإيرادات            من مجموعات حسابات الإيرادات (4xxx)
− تكلفة المبيعات     5101
= الربح الإجمالي
− مصروفات تشغيلية    5xxx (إيجار، رواتب، خدمات...)
= الربح التشغيلي
± فروق صرف ودخل/مصروف آخر
= الربح قبل الزكاة/الضريبة
```

- الإعداد: كل مجموعة من الشجرة موسومة بـ `income_statement_section` (REVENUE / COGS / OPEX / OTHER) لإخراج القائمة آلياً.
- مقارنة: الفترة الحالية مقابل نفس الفترة السابقة + نسبة التغير + الميزانية (إن وجدت).

## 11.4 قائمة المركز المالي

```
الأصول       (مجموعات 1xxx) — متداولة / غير متداولة
الالتزامات   (2xxx) — متداولة / طويلة الأجل
حقوق الملكية (3xxx) + صافي ربح الفترة (من قائمة الدخل)
تحقق: الأصول = الالتزامات + حقوق الملكية
```

- الأرصدة التراكمية حتى نهاية الفترة المحددة (وليس الفترة فقط).
- حساب الأرباح المحتجزة يظهر صافي الفترات غير الموزعة.

## 11.5 قائمة التدفقات النقدية

- **طريقة مباشرة**: من قيود النقدية (صندوق/بنك) مصنفة على حسابات الطرف المقابل: تحصيل عملاء، سداد موردين، رواتب، ... — تحتاج "وسم" حسابات الأطراف بأنواع التدفق (تشغيلي/استثماري/تمويلي).
- **طريقة غير مباشرة**: تبدأ من صافي الربح + تعديلات (إهلاك، تغيرات أرصدة ذمم ومخزون...).
- يُوصى بالطريقة المباشرة لأن الحركات مسجلة أصلاً على حسابات النقدية.

## 11.6 كشوف الحسابات

- كشف حساب عام (GL) لأي حساب: تاريخ، مرجع، وصف، مدين، دائن، رصيد تراكمي.
- كشف حساب مساعد (عميل/مورد/موظف/صندوق) من `account_links`.
- تصفية بالعملة (إظهار المبلغ الأصلي والمحول).

## 11.7 التقارير التشغيلية

| التقرير | المصدر |
|---------|--------|
| أعمار الذمم المدينة/الدائنة | أرصدة عملاء/موردين بتواريخ الفواتير |
| بطاقة صنف | حركات المخزون بالتكلفة |
| تقييم المخزون | stock_balances × avg_cost |
| المبيعات حسب صنف/عميل/مندوب/فرع | sales_invoices(+lines) |
| هامش الربح لكل فاتورة | إيراد − cogs_amount |
| تقارير الضرائب | document_taxes |
| مسير الرواتب | payroll_runs/lines |

## 11.8 تقنية التنفيذ

- **تعريف التقرير كبيانات**: كل تقرير موصوف بـ JSON (مصدر البيانات/SQL معلمي، الأعمدة، التجميعات، الفلاتر) — يسهل إضافة تقارير دون نشر كود.
- **تحكم بالصلاحيات**: صلاحية لكل تقرير؛ تقرير الرواتب مثلاً لمدير محدد.
- **التصدير**: Excel (مع الحفاظ على صيغ الأرقام)، PDF، CSV.
- **جدولة**: تقرير شهري يُرسل تلقائياً بالإيميل (طابور + قوالب).

### مثال تعريف تقرير (JSON)

```json
{
  "code": "trial_balance",
  "name_ar": "ميزان المراجعة",
  "params": [
    { "name": "fromPeriod", "type": "period", "required": true },
    { "name": "toPeriod",   "type": "period", "required": true },
    { "name": "branchId",   "type": "branch", "required": false }
  ],
  "dataset": {
    "sql": "SELECT a.code, a.name_ar, SUM(b.period_debit) d, SUM(b.period_credit) c FROM account_period_balances b JOIN accounts a ON a.id=b.account_id WHERE b.company_id=$companyId AND b.period_code BETWEEN $fromPeriod AND $toPeriod AND ($branchId IS NULL OR b.branch_id=$branchId) GROUP BY a.code, a.name_ar ORDER BY a.code"
  },
  "columns": [
    { "field": "code", "title": "الكود" },
    { "field": "name_ar", "title": "الحساب" },
    { "field": "d", "title": "مدين", "format": "money" },
    { "field": "c", "title": "دائن", "format": "money" }
  ]
}
```
