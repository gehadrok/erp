# 1. نظرة عامة ونطاق النظام

## 1.1 الهدف

بناء نظام ERP محاسبي متكامل يخدم الشركات الصغيرة والمتوسطة، ويغطي:

- الدورة المحاسبية الكاملة (قيود، دفاتر، ترحيل، إقفال).
- المشتريات والمبيعات والمخازن.
- الرواتب والأصول الثابتة.
- الضرائب والفاتورة الإلكترونية (المرحلة الأولى والثانية والثالثة).
- تقارير إدارية ومالية دقيقة في الوقت الحقيقي.

## 1.2 المبادئ التصميمية

1. **قيد مزدوج صارم**: لا حركة مالية بدون قيد محاسبي مرتبط بها.
2. **مصدر حقيقة واحد**: كل رقم في تقرير يمكن تتبعه إلى قيوده الأصلية.
3. **تعدد الشركات والفروع والعملات** من اليوم الأول (لا يُضاف لاحقاً).
4. **الفصل بين التسجيل والترحيل**: القيد يُسجل ثم يُرحّل، مع مراحل أعتماد.
5. **عدم حذف البيانات المالية**: كل تصحيح يكون بقيود عكسية أو تعديلية.

## 1.4 المتطلبات الوظيفية الرئيسية

### الإعدادات العامة
- FR-001: إدارة شركات متعددة بنفس النظام (عزل بيانات كامل).
- FR-002: إدارة فروع داخل كل شركة، مع إمكانية إسناد الحركات للفرع.
- FR-003: إدارة عملات متعددة بأسعار صرف يومية.
- FR-004: تسلسلات ترقيم تلقائية لكل نوع مستند ولكل فرع (قابلة للتهيئة بصيغة مثل `INV-{YYYY}-{SEQ:5}`).

### دليل الحسابات
- FR-010: شجرة حسابات هرمية (مجموعات وحسابات) قابلة للتعديل قبل الترحيل.
- FR-011: حسابات مرتبطة بكيانات النظام (مورد، عميل، صندوق، بنك، أصل، قسم) — "الحسابات المساعدة".
- FR-012: حسابات افتراضية قابلة للتهيئة (مبيعات، مشتريات، خصم مسموح، خصم مكتسب، فروق عملة، ...).

### محرك القيود
- FR-020: قيد يدوي متعدد الأطراف مع توازن إجباري (مدين = دائن).
- FR-021: قيود آلية مولدة من المستندات (فاتورة، سند صرف، ...).
- FR-022: دورة حياة القيد: مسودة → معتمد → مرحّل → ملغي/معكوس.
- FR-023: عكس قيد مرحّل بقيود عكسية (بدون حذف).
- FR-024: إقفال فترة مالية يمنع الترحيل إليها.

### المخازن
- FR-030: أصناف مع وحدات قياس متعددة وعوامل تحويل.
- FR-031: تكلفة متوسط مرجح (Weighted Average) و FIFO كخيار.
- FR-032: حركات: إضافة، صرف، تحويل بين مستودعات، تسوية جرد.
- FR-033: أرصدة مخزنية لحظية وطبقات تكلفة (layers) لنهاية كل يوم.

### المشتريات
- FR-040: ملف مورد مع شروط سداد وحساب مرتبط.
- FR-041: دورة: طلب شراء → أمر شراء → فاتورة شراء → دفع.
- FR-042: ربط فاتورة الشراء بحركة مخزنية وقيد محاسبي.
- FR-043: سلف وسحب للموردين والعملاء.

### المبيعات
- FR-050: ملف عميل مع حد ائتماني وتحذير عند التجاوز.
- FR-051: دورة: عرض سعر → فاتورة → مرتجع → تحصيل.
- FR-052: فوترة إلكترونية حسب اللوائح المحلية.
- FR-0553: تقارير أعمار الديون (Aging) والمدينين.

### الرواتب
- FR-060: هيكل وظيفي (إدارات، وظائف، عقد عمل).
- FR-061: بدلات واستقطاعات قابلة للتهيئة (ثابتة أو كنسبة أو معادلة).
- FR-062: تشغيل مسير شهري + قيد محاسبي مجمّع.
- FR-063: نهاية خدمة ومستحقات.

### التقارير
- FR-070: ميزان مراجعة بالتاريخ والفرع والعملة الأساسية.
- FR-071: قائمة الدخل، المركز المالي، التدفقات النقدية (طريقة مباشرة وغير مباشرة).
- FR-072: كشف حساب تفصيلي لأي حساب مساعد.
- FR-073: تقارير مبيعات/مشتريات/مخزون/رواتب تشغيلية.

## 1.5 المتطلبات غير الوظيفية

| المتطلب | الهدف |
|---------|-------|
| الأداء | ترحيل قيد < 200ms، تقرير ميزان مراجعة لسنة كاملة < 2s |
| التوفر | 99.5% خلال ساعات العمل |
| الأمان | TLS، تشفير كلمات المرور (argon2/bcrypt)، صلاحيات دقيقة |
| التدقيق | كل تعديل/حذف يُسجل بمن ومتى وقيم قبل/بعد |
| النسخ الاحتياطي | نسخ يومية + احتفاظ 30 يوم + اختبار استعادة ربع سنوي |
| قابلية الاستخدام | واجهة عربي/إنجليزي RTL، اختصارات لوحة مفاتيح |
| التوسع | دعم 100+ مستخدم متزامن، بيانات 10 سنوات |
