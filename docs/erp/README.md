# نظام محاسبي ERP — فهرس الوثائق

## قراءة سريعة

- أنت تبدأ من الصفر؟ ابدأ بـ `01-overview.md` ثم `02-architecture.md`.
- تريد بناء محرك القيود مباشرة؟ اذهب إلى `04-gl-engine.md` و `03-data-model.md`.
- لديك نظام قديم وتريد الربط؟ راجع `13-api-integration.md`.
- إعداد الضرائب والفاتورة الإلكترونية؟ راجع `10-tax-einvoice.md`.
